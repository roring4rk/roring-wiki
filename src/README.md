# Roring Server Wiki

This wiki documents **only what Roring does differently from vanilla pre-renewal Ragnarok Online**.
A player should be able to read this and be fully informed about our rates, systems and content
without needing generic RO knowledge.

Every entry uses the same template:

> Vanilla pre-re: *what the reference server does*.
> Ours: *what we do*.
> Why: *one line*.
> Source: *#issue / #PR*.

No entry exists without a source link, and generic RO tutorials are deliberately out of scope.

## Prior art

The "feature-by-feature differences" layout is inspired by
[UARO's features page](https://wiki.uaro.net/features-enhancements/); the text here is our own.
